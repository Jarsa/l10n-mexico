This module add the following features to the partner.

-  Add fiscal regime to partner.
-  Validate and format the VAT with company or person standard, raise a
   warning if it's incorrect.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Access a partner record
2. Define the country of the partner as Mexico, and set the VAT.
3. Define the fiscal regime.
